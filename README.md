# The-Glyph-Report
Pythoneering Unicode's "Non-linguistic" Glyph Set

When my 2 year old Dell Inspiration died last week, so too did the easy cut-and-paste access to Unicode via Windows 11.

Back on another O.S since then, all felt the need to quickly cut-and-paste those same once again, so we had Google A.I cobble this code together.

Enjoy.

p.s. Never to be confused with "The Book of Glyphs" as [shared here](https://github.com/soft9000/The-Book-of-Glyphs) 🤓
